# Deutsch-Lernpfad Unterstufe

Online-Lernpfad für Deutsch in der AHS-Unterstufe: **Rechtschreibung**, **Grammatik** und **Textsorten**, aufbauend von der Basis bis zum Schweren, mit Online-Übungen und Kontrollen für Lehrkräfte. Die Kapitel sind verschlüsselt und werden von der Lehrkraft mit Freigabe-Codes für die Klassen freigeschaltet.

Live: https://schmidh2.github.io/deutsch-unterstufe-lernpfad/
